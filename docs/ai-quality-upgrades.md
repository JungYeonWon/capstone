# 기존 AI 기능 품질 개선

## 계약 검토의 문맥 판단

- 의무 조항과 함께 제한·예외 인용, 적용 관계에 대한 설명, 확인 우선순위와 판단 보류 상태를 저장·표시한다. 위험 확률이나 법적 효력의 판정이 아니다.
- 원문과 별첨의 관련 조건을 함께 검토하고, 다른 의무의 상한을 적용하지 않도록 프롬프트를 보완했다. 추가 제한 표현이 근처나 명시적으로 참조한 자료에서 발견되면 적용 관계 확인 대상으로 낮춘다.
- AI가 제한 조건을 반영해 별도 위험 지적을 하지 않은 경우에도 원래 의무와 제한 조건의 서로 다른 인용을 검증해 `제한·예외 확인 메모`로 남긴다. 이 메모를 바탕으로 규칙 점검이 같은 부분을 다시 추가하는 것을 줄인다. 메모는 안전·해결 완료 판정이 아니다.
- 같은 유형·동일 근거의 지적을 묶되, 영향 설명·질문·관련 근거를 잘라내야 하는 경우는 따로 보존한다. 우선순위 높은 항목을 먼저 표시한다.
- 조건 인용도 원문 일치를 검증하고 검토 이력·PDF에 보존한다. 수정 전후 비교에 제한·예외 인용도 포함하므로 원래 의무가 같아도 예외가 바뀌면 변경을 확인할 수 있다.

## 요구사항 질문·답변

- 질문을 주제별로 구분하고 일반 질문, 기존 답변의 세부조건을 묻는 후속 질문, 상충 조건의 확인 질문을 구별한다. 이미 답한 같은 뜻의 기본 질문은 줄이되 미정·모름인 답변은 해결된 것으로 취급하지 않는다. 후속 질문은 실제 기존 답변 인용을 요구한다.
- 처음 입력과 답변에 모순이 있으면 양쪽 원문을 보여주고 사용자 결정을 요청한다. 사용자 역할이 같고 이메일 방식과 휴대폰 방식이 서로 배타적으로 명시된 경우는 AI가 놓쳐도 로컬 점검으로 보완한다. 다른 역할과 복수 허용 방식은 이 규칙으로 충돌 처리하지 않는다.
- 충돌 질문에 답하고 확정 표시하면, 당시 인용문에 대한 결정 정보를 함께 저장한다. 해당 인용문에만 결정을 적용하며 새로 바뀐 조건 전체를 자동 덮어쓰지 않는다. 충돌 확인 전에는 분석 화면에서 서류 저장을 막는다.
- 직접 입력과 답변의 `확정한 요구사항으로 반영`은 사용자 표시다. 서버는 인용한 자료의 표시와 충돌 여부를 확인해 `사용자 확정 근거 / 확정 필요 / AI 제안`을 구분한다. 체크가 AI 해석의 정확성이나 계약상 합의를 보장하지 않는다. 입력·답변을 편집하면 확정 체크를 해제한다.
- 검수 기준이 단순히 정상 작동·요구사항 충족으로 끝나면 시험 절차·입력·기대 결과·통과 조건을 확인하도록 표시한다. 성능 수치나 기한은 만들지 않는다.

## 재분석 시 편집 내용 보존

1. 현재 작성 중인 초안도 전송 미리보기에 포함하고 동의한 내용만 AI에 보낸다. 초안은 사실·합의의 증거가 아니며 수정과 관계없는 문구를 유지하도록 지시한다. 초안 편집 후에는 기존 전송 미리보기와 동의를 무효화한다.
2. 새 분석을 받아도 현재 초안과 견적 입력은 그대로 둔다. 제목, 항목 본문, 추가·삭제·구성 변경은 `재분석 변경 제안`에 분리한다. 기존 AI 기준과 달라진 사용자 문구는 보호 표시한다. 과거 기준이 없는 이전 작업은 보수적으로 보호한다.
3. 항목별로 `새 제안 반영 / 기존 내용 유지`를 선택한다. 섹션 ID와 제목 일치로 연결하며 순서만으로 임의 대응하지 않는다. 이름이 달라 대응이 불명확하면 추가·삭제 제안으로 따로 표시한다. 비교 이후 원문이 바뀌었으면 반영을 거부한다.
4. 미선택 제안은 현재 작업과 함께 암호화 저장하고 다시 열 수 있다. 미선택 제안이 있는 초안은 편집·서류 생성을 잠시 막고, 다음 재분석 전에 선택을 끝내도록 한다. 나머지 초안과 견적 입력은 유지한다.

## 호환성·검증 범위

기존 암호화 JSON에 선택 상태·이전 AI 초안·확정 표시 등을 추가해 새 DB 마이그레이션이나 환경변수는 필요 없다. 비교 상태를 포함한 작업 저장 한도는 640KB이며 AI 전송은 자료·답변·작성 중 초안을 합쳐 32,000자다. 재분석 비교·규칙 점검에 추가 AI 호출은 없다. 기존 이력은 기본값으로 읽고 소급 재분석하지 않는다. 운영에는 서버·웹을 함께 배포해야 한다.

합성 사례로 문맥 근거 검증, 중복 병합, 순서 정렬, 질문 반복 억제, 미정 답변 유지, 충돌·사용자 결정, 편집 보호, 선택 반영 및 암호화 저장을 검증한다. 실제 OpenAI의 가상 자료 응답과 별도의 고정 응답 브라우저 테스트를 구분해 수행했다. 이는 임의 계약의 법적 판단 정확도나 모든 표현의 의미 중복·충돌 탐지를 보장하는 평가가 아니다.
