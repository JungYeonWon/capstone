# 안내문 분석 사용·검증

## 사용하기

계약 화면 → **안내문 분석**에서 텍스트를 붙여넣거나 PDF·한글(HWP/HWPX)·Word(DOCX)·UTF-8 TXT를 가져옵니다. 기본 분석은 외부 전송 없이 사용할 수 있습니다. AI 보완은 전송 내용을 확인하고 해당 요청에 동의해야 합니다.

1. **안내문 분석하기**를 누릅니다.
2. 서류별 원문 근거, 필수·조건부 여부와 제출 정보를 확인합니다.
3. **확인한 결과 적용·저장**으로 반영합니다. 기존 결과에서 제외될 항목은 미리 표시됩니다.
4. 조건부 항목이 회사에 해당하면 필수로 바꾸고 준비 메모를 입력합니다.
5. **작성 가능한 양식 찾기 → 서류 생성·연결**로 문서를 준비합니다. 기존 서류가 있으면 재사용합니다. 외부 증빙은 직접 준비합니다.
6. 저장 완료를 확인하고 **제출 전 통합 점검**을 실행합니다. 미완료 목록과 원문 변경 후 미반영 상태를 확인할 수 있습니다.

분석은 원문 검토를 보조합니다. 문서 생성·연결만으로 준비 확인을 체크하지 않으며, 기한 자동 확정·실제 제출·첨부 진위 검증은 수행하지 않습니다. 일반 HWP 5.x, HWPX와 DOCX의 본문·표 텍스트를 읽습니다. 파일은 최대 3MB, 추출 텍스트는 20,000자이며 PDF는 20페이지까지입니다. 스캔 OCR, HWP 암호·배포용·DRM 문서, 구형 HWP·Word DOC는 지원하지 않습니다. 제한을 해제하거나 HWPX·DOCX로 저장해 사용하세요. 이미지·도형·머리말·각주 내용과 표 읽기 순서는 원문에서 확인해야 합니다.

## 데이터·배포

소유자 확인, CSRF, AI 전송 동의 해시, 암호화 저장과 revision 충돌 검사를 유지합니다. 신규 칼럼 없이 기존 `workspace_states.payload`에 제출 정보와 적용 원문을 저장하므로, 이전 작업의 `docs/workspace-schema.sql`을 적용했다면 추가 DB 변경은 없습니다. HWP 읽기에는 `olefile==0.47`을 사용하며 `server/requirements.txt`에 포함했습니다. 한컴·Word 설치나 별도 변환 서버 없이 파일에서 텍스트를 직접 읽고 원본을 영구 저장하거나 외부로 보내지 않습니다. 로컬 코드와 운영 배포·환경변수는 별개입니다.

## 재현 가능한 검사

- 서버: `python -W ignore::DeprecationWarning -m unittest discover -s tests -q` (API 키는 빈 환경변수로 실행)
- 웹 재분석 상태 보존: `node --test tests/notice.test.mjs`
- 웹: `npx next build --webpack`, `npm run lint`

가상 안내문 예시:

```text
제출서류
1. 착수신고서 1부
2. 과업수행계획서 1부
3. 사업자등록증, 통장사본 (해당 시)
4. 현장방문계획서 1부
5. 견적서 제출 생략 가능
제출기한: 계약 체결 후 7일 이내
제출방법: 이메일 또는 방문 접수
제출처: 가상시청 계약팀
문의처: 가상 계약담당
유의사항: 사본에는 원본대조필을 표시하세요.
```

예상 결과는 서류 5개(필수 4개·조건부 1개), 제출 정보 5개입니다. 생략 가능한 견적서는 목록에서 제외합니다. 실제 정보가 없는 가상 계정·격리 DB로 검증하며 테스트 데이터와 키는 Git에 포함하지 않습니다.

2026-11-05 검증: 실제 OpenAI 분석으로 위 서류·제출 정보를 확인했습니다. 브라우저에서 결과 적용 → 착수계 생성·연결 → 같은 서류 재사용(1건 유지) → 준비 상태·메모 저장 → 새로고침 복원 → 원문 변경 후 재분석 경고 → 재분석 적용 및 기존 준비 상태 보존을 확인했습니다. 웹 빌드·타입 검사 통과, 린트 오류 없음(기존 API 내비게이션 경고 1개)입니다.

한글·Word 검증: 가상 안내문을 실제 DOCX·HWPX와 한컴에서 저장한 HWP 파일로 만들어 서류 목록과 표의 제출기한을 확인했습니다. 자동 테스트는 메타데이터 없는 가상 CFB HWP를 사용하며 압축·비압축·확장 레코드, 제한 문서, 손상 파일, XML 엔터티·압축 크기, 다른 계정의 접근 차단을 검사합니다.
