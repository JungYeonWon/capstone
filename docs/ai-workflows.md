# AI 업무 도우미

계약 상세의 **AI 업무 도우미**에서 다음 세 기능을 연다.

| 기능 | 입력과 결과 | 저장할 수 있는 서류 |
| --- | --- | --- |
| 추가 요청 영향 분석 | 고객 요청과 선택한 기존 계약 자료를 비교하고 범위·일정·비용·검수의 확인 사항을 정리 | 과업변경 합의서, 협의 메일 초안 |
| 요구사항 구체화 | 서비스 설명을 기능·산출물·검수·제외 범위·일정으로 정리하고 AI 질문에 추가 답변 | 과업지시서, 견적 구성 초안과 사용자 입력 계산표 |
| 회의록 후속 업무 | 합의 후보·논의·미결 사항·후속 업무를 원문 근거와 함께 분류 | 회의 확인서, 확인 메일, 필요 시 변경 합의서 초안 |

주소는 `/contracts/{id}/assistant/change`, `/requirements`, `/meeting`이다. 각 기능에서 입력 → 전송 미리보기 → OpenAI 전송 동의 → 분석 → 편집 → 작업 저장 또는 서류 저장 순서로 사용한다. 입력을 바꾸면 전송 동의가 해제되고 이전 결과의 서류 저장이 막힌다. 추가 답변을 반영하려면 다시 분석한다. 같은 질문에 이미 답변했다면 정확히 일치하는 반복 질문은 서버에서 제거하며, 의미가 비슷한 후속 질문은 사용자 확인이 필요하다.

## 자료와 초안의 취급

- 계약명·과업 내용은 체크한 경우에만 포함한다. 회사 계좌·인감·전체 양식 라이브러리는 전송하지 않는다. 자체/맞춤 저장본 1개 및 PDF·HWP·HWPX·DOCX·TXT 파일 최대 5개를 선택할 수 있다. 파일당 3MB, 입력·참고 자료·답변 합계 32,000자다. 이미지 스캔의 OCR·음성 전사는 지원하지 않는다.
- 업로드 자료는 `분석할 입력`과 `기존 계약·참고 자료`로 구분한다. 추출 경고와 텍스트를 화면에서 확인할 수 있다. 추가 요청 분석은 기존 자료가 필요하다. 계약 개요만으로 실제 계약 범위를 판단하기에는 부족할 수 있다.
- 미리보기의 마스킹 문자열과 실제 AI 사용자 메시지는 동일하다. 입력이나 저장본 내용이 달라지면 기존 동의 해시로 실행할 수 없다. AI 호출은 실행당 1회, 최대 출력 7,000토큰이며 기능 전체에 기존 계정/IP 제한을 함께 적용한다. 전송은 감사 이력에 기록한다.
- AI 결과는 스키마와 인용 원문을 검증한다. 인용 검증은 문구의 존재를 확인하며, AI의 해석이나 합의 판단의 정확성을 보장하지 않는다. 요청·기존 자료를 함께 인용하지 못한 범위 판단은 보류한다. 회의 후속 업무의 담당자·기한은 회의 원문 인용에서 그대로 확인된 값만 유지한다.
- 기능별 마지막 작업 1개는 기존 `workspace_states`의 암호화 JSON에 명시적으로 저장한다. 다른 창에서 먼저 저장하면 409로 덮어쓰기를 막는다. 브라우저 localStorage에 문서 내용을 저장하지 않는다. 30일간 수정되지 않은 작업은 기존 정리 정책의 대상이다. 원본 업로드 파일은 새로 보관하지 않으며 추출 텍스트는 작업 저장 시 포함된다.
- 초안은 편집 후 별도 확인을 거쳐 개인 맞춤 서류로 저장한다. 원래 계약·문서를 바꾸거나 메일을 발송하지 않는다. 새 서류는 `draft`이며 기존 최종본 확인·재인증·인감 승인 절차가 적용된다. 맞춤 양식은 기존 계정당 50개 제한을 공유한다.
- 견적 금액은 사용자가 입력한 수량·단가만으로 서버 Decimal과 브라우저 정수 계산을 통해 소수 둘째 자리에서 반올림한다. 부가세·할인은 적용하지 않는다. 수량은 0 초과 10,000 이하, 단가는 0 이상 1억 원 이하, 최대 30개 항목이다. 견적 문서에 계산표가 추가되며 일반 ‘초안 복사’에는 계산표가 포함되지 않는다.

## 운영 반영과 검증

기존 OpenAI 환경변수와 `workspace_states` 테이블을 재사용하므로 새 환경변수나 DB 마이그레이션은 필요 없다. 코드 병합 후 프런트엔드와 서버를 함께 배포해야 한다. 실제 키·자료·데이터베이스는 커밋하지 않는다.

`server/tests/test_ai_workflows.py`는 권한·CSRF·동의 갱신, 정확한 전송 본문, 질문 답변, 원문 인용, 암호화·저장 충돌, 필수 항목 보존, 역할/자료 구분, 초안 생성과 견적 계산을 검증한다. `web/tests/ai-workflows.test.mjs`는 소수·고액 계산 일치와 잘못된 입력 차단을 검증한다. 합성 계정과 별도 DB로 실제 OpenAI 호출 및 브라우저 저장 흐름도 확인한다. 이 검증은 실제 계약 해석이나 합의 분류의 정확도 평가를 대신하지 않는다.
